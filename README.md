# AI-Powered Resume Screening System

An AI-powered web application that analyzes resumes,
matches candidates with job requirements, and provides
explainable recommendations to recruiters.

## Technology Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Java
- Spring Boot
- Spring Security

### AI Service
- Python
- FastAPI
- Sentence Transformers
- Scikit-learn

### Database
- PostgreSQL
- pgvector

### DevOps
- Docker
- GitHub

## Architecture

Modular Monolith + Separate AI Microservice

## Project Structure

- frontend/
- backend/
- ai-service/
- database/
- docs/
